# 图帧

全屏看图的网页应用，带一个可以随便拖动、随便调大小的时钟。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 主程序，所有功能都在这一个文件里 |
| `manifest.json` | 让浏览器能把它"添加到主屏幕"当独立 app |
| `sw.js` | 离线缓存，装到桌面后断网也能打开 |
| `icon.svg` / `icon-512.png` | 图标 |

## 三种用法

### 1. 直接打开（最快，但图片留不住）

把 `index.html` 传到手机，用浏览器打开即可用。**注意**：`file://` 协议下 Chrome 会禁用 IndexedDB，程序会自动降级到 localStorage（约 10 张、且某些环境重开就清空）。适合先看看长什么样。

### 2. 装到桌面当 app（推荐）

把整个文件夹传到一个静态托管上，用手机浏览器打开网址，然后：

- Android Chrome：右上角菜单 →「添加到主屏幕」/「安装应用」
- iOS Safari：分享 →「添加到主屏幕」

装好后是独立窗口、没有地址栏，图标在桌面上。这种方式图片能长期保存（IndexedDB 可用）。

免费托管可选：GitHub Pages、Cloudflare Pages、Netlify Drop（拖拽上传即可）。
只要拿到一个 `https://` 地址就行，本地不需要服务器。

### 3. 以后想打成 apk

见对话里的结论：官方 build-tools 里的 `aapt2`、`aapt`、`zipalign` 只有 x86-64 二进制，沙盒是 aarch64，直接构建跑不起来，需要 qemu 模拟或换构建机。先不折腾。

## 功能

**看图**
- 全屏显示，完整显示 / 铺满 两种模式
- 模糊背景垫底（竖图不黑边）
- 缓慢推拉（Ken Burns）
- 双指缩放、放大后单指拖动、双击放大/还原
- 左右滑动切换，点一下呼出/收起控制条

**图库**
- 多选导入、拖拽导入
- 九宫格管理，单击切换，右上角 × 删除
- 排序：添加顺序 / 按名称 / 随机
- 一键清空
- 导出备份 / 恢复备份（JSON，含图片和全部设置）

**轮播**
- 自动播放，间隔 2–60 秒可调
- 五种切换效果：淡入淡出、左右滑动、缩放、黑场、随机

**时钟**（可整体关掉）
- 大号 时:分，12/24 小时制
- 秒、日期、星期、农历、节气
- 倒计时（默认 2026年12月19日 初试，名字和日期都能改）
- 自定义一行文字
- 字号 20–180、颜色 8 种、不透明度、毛玻璃底板
- **直接拖动时钟改位置**，双击复位到顶部居中

**其他**
- 屏幕常亮（Wake Lock，浏览器支持时）
- 图片信息（文件名 + 分辨率）短暂显示
- 锁定模式：防止误触，长按 2 秒解锁
- 全屏按钮

## 已知限制

- 图片存在浏览器本地，换浏览器、清缓存、卸载都会丢，重要图片请用「导出备份」
- 各浏览器对屏幕常亮的支持不一致，iOS 较新的系统才行
- 没有图片时显示引导页
- 农历用浏览器内置的中文历法（Intl），节气用近似公式，个别年份可能差一天
